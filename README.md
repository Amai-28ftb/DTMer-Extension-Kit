## 説明
音声ファイルを読み込んで色々できるやつです


AviUtl 無印で配布されていた akkadaska氏の [aviutlScripts](https://github.com/akkadaska/aviutlScripts) を参考にさせていただいております。
上記の Script は README と配布ページより「自由に利用、改変、再配布可能」と記載されてる事を確認済みです。




## 配布先について
- [Github](https://github.com/Amai-28ftb/DTMer-Extension-Kit)：多分ここです。


## 注意事項
- AIにコーディングを手伝って貰っています。使用前にご了承ください。
- GitHub Copilot が提案するコードは著作権的にクリーンのはずですが、万が一問題がありましたら連絡ください。該当箇所を修正します。
- また、動作があり得ない程重かったので一部の .dll化(.mod2)化。それに伴うコードとコメントの整理に Claude Code を利用しています。
- 現在はβ版ですので、バグや不具合が多いと思いますがご了承ください。

## 使用方法
- カスタムオブジェクト、アニメーション効果、トラックバーから呼び出してください。
- 詳細な説明は Notion をご覧ください（工事中）。

## 内容物
### @DTMer Extension Kit.obj2
- AulNation：左右ミラーした円形音声波形です。
- AulNation_P：音声同期する左右ミラーのパーティクルです。
- AulCity：音声波形です。
- AulVillage：PCM波形です。
- AudioWaveform：音声波形です。
- VU_Meterもどき：VU_Meterもどきです。
- AulMountain：音声波形の連なりです。
- AudioSpectrum_mk2：おまけの音声波形です。
### @DTMer Extension Kit.tra2
- Audio_Sync：[AUL Receptor](https://a2cw.sevenc7c.com/package/Amai_28ftb.AULReceptor)の『@Audio_Receptor』が必須です。
### DEK_module.mod2
- 軽量化のために処理を一部dllに任せています。そのため、無いと動きません。
### audio_futabuffer
- オーディオバッファ読み取り用です。これを利用して独自の Script を作成していただいても構いませんが、当方は一切の責任を負いません。


## 規約的な何か
- 感染性ライセンスが嫌いなので、特定のライセンスは設けていません。
- Script使用した動画の親登録は任意です。親登録通知が来た動画は全て見に行ってますが、しなくてもOKです。
- 私が配布先を全て削除し、失踪した場合は再配布を認めます。
- フォーク版の作成を認めます。条件は以下の通りです。以下の条件が守られている場合、事前連絡は無くても構いません。
  - ファイル名は元となった Script と被らない様にお願い致します。被らなければファイル名は自由です。もし名前を引き継ぐ場合は『@AUL Receptor_by〇〇フォーク版.obj2』の様に完全一致にならない様にしてください。
  - 上書き保存で相互に動作保証される互換性があるならば同名でOKです
  - 詳しい連絡先は下記をご覧ください。
